CONCORD / PRIVACY

Your messages stay in your archive.

Effective September 22, 2026 · Published by Krishi Attri

Concord is an independent Chrome extension published by Krishi Attri. It creates a downloadable archive of Discord server channels a Discord bot can access. Concord is not created by, affiliated with, sponsored by, or endorsed by Discord Inc. Questions or privacy requests: krishiattriwork@gmail.com.

Information Concord processes

When you choose to export, you provide a Discord bot token and server ID. Concord temporarily holds the bot token in Chrome session storage to open the long-running export tab, removes it from session storage as soon as that tab starts, then keeps it in that tab’s memory only until the export ends. Concord sends the token to Discord over HTTPS as bot authentication. The token is not sent to Concord’s publisher or any other service.

Discord returns the server and channel details and the message history the bot is authorized to read. This can include channel and server names and IDs, message text, authors and user IDs, timestamps, replies, embeds, reactions, attachment details, and media URLs or files. Discord’s response depends on the bot’s permissions and Discord’s Message Content access rules.

How the information is used

Concord uses the token only to authenticate requests to discord.com/api. It uses the returned server data only to build the export you initiated. The extension creates a ZIP in the browser containing export.ndjson and Discord-hosted attachments, embed images, stickers, and custom emoji it can download from Discord’s CDN. The current per-file and per-archive media limits are 150 MiB and 700 MiB. Media from other hosts is kept as a URL/status in the NDJSON rather than fetched. Files are saved through Chrome’s normal download flow to the location configured by you.

Concord has no analytics, advertising, developer backend, account system, or remote logging. The publisher does not receive or have access to your token, Discord messages, or archive files. The extension does not sell or share this data. Discord receives API requests because Discord operates the API and server you asked Concord to export.

Storage and retention

The bot token is not saved to Chrome local or sync storage, cookies, or any publisher system. Chrome session storage is used only for the brief handoff from the setup popup to the export tab; the export tab deletes that handoff before making requests. The token is cleared from the extension’s active variables when the export finishes or fails. Message data, downloaded media, and the ZIP are held temporarily in the export tab’s memory while the archive is built and downloaded. Its temporary download URL is revoked when you close the export tab; close the tab after the download finishes to release that in-memory copy. Concord’s publisher receives no copy. The downloaded archive is under your control and may contain personal communications; protect it and delete it when no longer needed.

Security and access

Discord API requests use HTTPS. The token is sent only in the Authorization header to Discord API requests and is never put into a URL, log, or downloaded file. Concord does not request a normal Discord user token or automate a user account. Use a dedicated Discord bot with only the permissions required for the channels you intend to archive, and reset its token in the Discord Developer Portal if you believe it was exposed.

Your choices

You decide when to enter the bot token, which server ID to export, and when to start the export. Concord displays a data-use notice and asks you to affirmatively authorize the export before it accesses Discord data. You may close the extension before starting to cancel. Once a ZIP is downloaded, delete it using your normal file manager if you no longer want it.

Discord policy and AI use

The NDJSON format is structured for parsing by many tools. That format does not grant rights to reuse message content. Discord’s Developer Policy currently says API message content must not be used to train machine-learning or AI models, including LLMs, unless Discord has granted express permission. You are responsible for following Discord’s current terms and obtaining any permissions required for later use or disclosure of an archive.

Chrome Web Store Limited Use

Concord uses information obtained through Discord API access only to provide the user-requested server archive feature. It does not use or transfer that information for personalized, retargeted, or interest-based advertising; does not sell it; and does not permit human review by the publisher. The only service receiving the bot-authenticated API requests is Discord, as necessary to provide the export requested by the user.
