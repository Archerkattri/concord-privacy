CONCORD / PRIVACY

Your messages stay in your archive.

Effective September 22, 2026 · Published by Krishi Attri

Concord is an independent Chrome extension published by Krishi Attri. It creates a local archive from server channels visible to the account signed in to the Discord tab where the user opens Concord. It is not created by, affiliated with, sponsored by, or endorsed by Discord Inc. Questions or privacy requests: krishiattriwork@gmail.com.

Information Concord processes

When you choose to export, Concord reads the active Discord page’s signed-in session credential in the page’s main JavaScript context and uses it only as the Authorization header for Discord API requests. The credential is not sent to Concord’s popup, extension storage, publisher, analytics, or another service.

Discord returns the selected servers, channels, threads, and message history visible to your account. This can include names and IDs, message text, authors and IDs, timestamps, replies, embeds, reactions, attachment details, and media URLs or files.

How the information is used

Concord uses the active session only for Discord API requests needed to build your export. The ZIP contains export.ndjson and accessible Discord-hosted attachments, embed media, stickers, and custom emoji. Media hosted by other providers is recorded as a URL/status in the NDJSON and is not fetched. Downloads are limited to 150 MiB per file and 700 MiB of media per archive. Files are saved through Chrome’s normal download flow.

Concord has no analytics, advertising, developer backend, account system, or remote logging. The publisher does not receive your session credential, messages, or archive. Discord receives API requests and Discord CDN hosts may serve requested media.

Storage and retention

Concord does not save the session credential to extension storage, cookies, logs, URLs, or the downloaded ZIP. The page-world bridge reads it from Discord’s page storage when making a request and does not return it across the page/extension messaging boundary. Message data, media, and the ZIP are held temporarily in the Discord tab’s memory while the archive is assembled. Closing the export progress tab cancels a running job; closing the Discord tab also ends the work. The publisher receives no copy. The downloaded archive may contain sensitive communications; protect it and delete it when no longer needed.

Security and access

Discord API requests use HTTPS. Concord does not collect your password or send your session credential to its publisher. The credential is used only in the Discord page context to authorize the export you initiated. Concord is not affiliated with Discord; use it only with data you are authorized to archive.

Your choices

You decide which servers to select and when to start each export. Concord displays a data-use notice and asks for confirmation before reading selected data. Close the export tab to cancel a running job. Once downloaded, delete the ZIP using your normal file manager if you no longer want it.

Format and downstream use

NDJSON is structured for parsing by ChatGPT, Codex, and other tools, but format compatibility does not grant permission to reuse or disclose message content. You are responsible for obtaining any rights or permissions required for later use.

Chrome Web Store Limited Use

Concord uses information accessed through the signed-in Discord tab only to provide the user-requested archive. It does not use the information for advertising, sell it, or permit publisher human review. Discord receives the API requests and Discord CDN hosts may serve requested media; no other service receives the message data or archive from Concord.

Policy updates

If Concord’s data practices change, this policy and the in-product disclosure will be updated. The effective date at the top identifies the current version.
